# H1DIPAMP Integration Guide

## Overview

The `H1DIPAMP` class extends `H1AMP` to integrate DIP (Diffusion-based Imitation Policy) generated motions into the observation computation. Instead of using pre-recorded motion sequences from the motion library, it uses DIP to generate future motions based on recent motion history.

## Key Components

### 1. Motion History Management
- **Purpose**: Store past 20 frames of motion data for each environment
- **Storage**: `self.dip_motion_history[env_id]` contains robot states for past frames
- **Update**: `update_motion_history()` shifts buffer and adds current state

### 2. DIP Motion Generation
- **Trigger**: Every 20 frames (`dip_generation_interval`) or when buffer is invalid
- **Process**: `generate_dip_motion()` uses past 20 frames to generate future 40 frames
- **Storage**: `self.dip_motion_buffer[env_id]` contains generated future motions

### 3. Modified Observation Computation
- **Method**: `_compute_mimic_observations()` now uses DIP-generated motions
- **Fallback**: Uses original motion library if DIP generation fails
- **Frame Selection**: Selects appropriate frame from 40-frame DIP sequence

## Usage Example

```python
# 1. Create environment
env = H1DIPAMP(cfg, sim_params, physics_engine, sim_device, headless)

# 2. Create and set DIP model
dip_model = YourDIPModelWrapper("path/to/model.pth")
env.set_dip_model(dip_model)

# 3. Run simulation
obs = env.reset()
for step in range(num_steps):
    actions = policy(obs)  # Your trained policy
    obs, _, rewards, dones, info = env.step(actions)
    
    # Monitor DIP generation status
    dip_info = env.get_dip_motion_info()
    print(f"Valid DIP buffers: {dip_info['valid_buffers']}/{dip_info['total_envs']}")
```

## Configuration Parameters

You can adjust these parameters in the `__init__` method:

```python
self.dip_generation_interval = 20  # Generate new motion every N frames
self.dip_history_length = 20       # Past frames for DIP input
self.dip_future_length = 40        # Future frames generated by DIP
```

## Benefits

1. **Dynamic Motion Generation**: Create diverse motions based on current context
2. **Adaptive Behavior**: DIP can generate motions that respond to current robot state
3. **Reduced Dataset Dependency**: Less reliance on pre-recorded motion sequences
4. **Creative Motion**: Potential for novel motion patterns not in training data
